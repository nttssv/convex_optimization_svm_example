# SVM project draft bundle

This folder is a self-contained snapshot of the current report and its
reproducible artifacts.

## Main files

- `cgh_hard_margin_project_report.tex`: report source.
- `output/pdf/cgh_hard_margin_project_report.pdf`: final rendered report.
- `data/`: CSV and spreadsheet versions of the synthetic project dataset.
- `scripts/`: hard-margin, linear soft-margin, and RBF-kernel analyses.
- `output/csv/`: full-precision numerical results and two-decimal display
  columns used by the report.
- `output/csv/svm_grid_pareto_frontier.csv`: linear and RBF grid settings,
  dominance status, and Pareto-optimal settings.
- `output/tables/`: generated LaTeX table fragments.
- `output/figures/`: generated figures plus seven committed static teaching
  assets: `feature_distributions`, `farkas_lemma_schematic`,
  `convex_hull_overlap_2d`, `fig_step3_c_grid`, `fig_step3_pareto`,
  `fig_step3c_pc_boundary`, and `fig_step4_rbf_pc_boundary`. The static assets
  illustrate shipped calculations but are not regenerated by the scripts.
- `output/figures/svm_grid_pareto_frontier.*`: reproducible Pareto chart for
  validation AUROC versus the train--validation AUROC gap.
- `output/csv/primal_optimizer_comparison.csv` and
  `output/figures/primal_optimizer_comparison.*`: controlled stochastic
  subgradient, Heavy Ball, and Nesterov-style comparison at the selected
  $C=0.01$ for Section 6.7.
- `output/xlsx/`: ten-observation teaching workbook.

The report-producing scripts are listed in the reproduction sequence below.
`svm_convergence.py`, `svm_cv_eval.py`, and `svm_diagnostics_from_data.py` are
legacy exploratory utilities and are not sources for any reported headline
number or included figure; `_pubstyle.py` is the shared plotting-style helper.

## Reproduce the analyses

The recorded reference environment uses Python 3.14.3. Install the pinned
packages before running the analysis sequence:

```bash
python3 -m pip install -r requirements.txt
```

Run these commands from the repository root, with `scripts/` on
`PYTHONPATH` (the soft-margin and RBF scripts import the sibling module
`linear_hard_margin_svm`, so they fail with `ModuleNotFoundError` if it is
not importable):

```bash
export PYTHONPATH="$PWD/scripts"
python3 scripts/build_descriptive_tables.py
python3 scripts/linear_hard_margin_svm.py
python3 scripts/build_full_data_infeasibility_certificate.py
python3 scripts/build_svm_primal_dual_toy_example.py
python3 scripts/build_hard_margin_teaching_workbook.py
python3 scripts/linear_soft_margin_svm.py
python3 scripts/compare_primal_optimizers.py
python3 scripts/kernel_rbf_svm.py
python3 scripts/build_seed_robustness.py
python3 scripts/build_boundary_sensitivity.py
python3 scripts/build_baseline_comparison.py
```

The scripts read the dataset via paths relative to the repository root,
so they must be launched from here (not from inside `scripts/`). Grid searches
use `n_jobs=1` deliberately so the recorded workflow also runs in restricted
or low-resource environments without changing the numerical procedure.

## Rebuild the PDF

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error \
  -outdir=output/pdf cgh_hard_margin_project_report.tex
latexmk -pdf -interaction=nonstopmode -halt-on-error \
  -outdir=output/pdf cgh_svm_slides.tex
```

Across 20 fold-assignment seeds, both SVMs have mean outer-fold AUROC about
0.94. The linear soft-margin SVM is preferred for parsimony: the RBF kernel
does not provide a stable improvement and shows severe overfitting for large
values of gamma. The Pareto and extended-boundary analyses are tuning
diagnostics and do not replace the untouched nested outer-fold comparison.
